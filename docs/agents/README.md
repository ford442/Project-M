# Agent docs

Prompts, plans and checklists written for coding and preset-authoring agents
(Grok, Kimi, Codex, Claude). `presets/agent_manifest.json` indexes the ones an
agent should start from.

- [`kimi_preset_authoring_plan.md`](kimi_preset_authoring_plan.md) — the preset
  authoring runbook (create / upgrade / validate), with the screenshot-capture
  budget CI enforces.
- [`briefs/`](briefs/) — creative briefs for the `milk011`–`milk015` presets in
  `presets/custom/` (each preset's header comment names its brief).
- [`grok/`](grok/) — task handoff templates, implementation plans and review
  checklists (start at [`grok/README.md`](grok/README.md)).
